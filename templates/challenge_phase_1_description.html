基于大语言模型的 Blocksworld 任务规划实验

Blocksworld 是 AI 规划领域的经典问题：给定若干积木的初始排列，需要通过一系列动作将其变换为目标排列。本挑战考察参赛者能否利用大语言模型（LLM）来解决规划问题。

两种方法路线

题目方法核心挑战
Q1 纯 LLM Prompt 规划 通过设计 Prompt，让 LLM 直接输出动作序列 Prompt 工程、状态追踪、输出解析
Q2 LLM + PDDL 规划 让 LLM 将任务翻译成 PDDL problem 文件，由经典规划器求解 NL→PDDL 翻译、规划器集成、输出清洗

评测环境

  • 积木世界：4 种动作（PICKUP, PUTDOWN, UNSTACK, STACK），5 种谓词（on, ontable, clear, holding, handempty）
  • 任务集：21 个隐藏任务，跨度从 3 块积木到 9 块积木
  • 输入格式：纯自然语言描述（无结构化状态）
  • LLM 后端：统一评测，参赛者无需自行配置 API

评分

  • Q1 目标达成率 → 满分 25 分
  • Q2 目标达成率 → 满分 30 分
  • 机器评分满分 55 分（剩余 45 分由教师人工评定）
