提交指南

提交文件格式

提交一个 zip 压缩包，包含以下两个 Python 文件：

submission.zip
├── q1_llm_prompt_planner.py   # Q1 纯 LLM Prompt 规划器
└── q2_llm_pddl_planner.py     # Q2 LLM + PDDL 规划器

Q1 接口要求 q1_llm_prompt_planner.py

def build_prompt(task: dict) -> str
def parse_llm_output(response: str) -> list[str]
def plan_with_llm(task: dict, llm_client) -> list[str]

Q2 接口要求 q2_llm_pddl_planner.py

def build_pddl_prompt(task: dict, domain_pddl: str) -> str
def generate_problem_pddl(task: dict, domain_pddl: str, llm_client) -> str
def solve_pddl(domain_path: str, problem_path: str) -> list[str]
def plan_with_llm_pddl(task: dict, domain_path: str, llm_client) -> list[str]

task 字典结构

{
    "task_id": "task_02",
    "blocks": ["A", "B", "C"],
    "natural_language": "...",
    "initial_state": [...],   # 隐藏任务中为空 []
    "goal_state": [...]       # 隐藏任务中为空 []
}

llm_client 用法

response = llm_client.chat(prompt)  # → str

限制

  • Q1：禁止使用 PDDL 规划器、搜索算法、硬编码答案
  • Q2：必须调用 PDDL 规划器（pyperplan），不可修改 domain.pddl
  • 代码不能依赖外部网络请求（API 调用通过 llm_client 进行）

参考资源

  • Blocksworld 动作用于 PICKUP, PUTDOWN, UNSTACK, STACK
  • PDDL 规划器：pyperplan（pip install pyperplan）
